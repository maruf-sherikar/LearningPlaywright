# JavaScript Keywords Notes

## 1. What is a keyword?
A keyword is a reserved word in JavaScript that has a special meaning and purpose in the language. It cannot be used as a variable name, function name, or class name.

Example:
- `if` is used to make decisions.
- `function` is used to create functions.
- `return` is used to send a value back from a function.

## 2. Why are keywords important?
Keywords help JavaScript understand the structure of the code. They are used for:
- controlling flow
- declaring variables
- defining functions
- handling errors
- working with loops and conditions

## 4. Simple examples

### `if` keyword
```javascript
let age = 18;
if (age >= 18) {
    console.log("Adult");
}
```

### `function` keyword
```javascript
function greet() {
    console.log("Hello");
}
```

### `for` keyword
```javascript
for (let i = 0; i < 3; i++) {
    console.log(i);
}
```

## 5. Important note
Some words such as `true`, `false`, and `null` are also considered literals, but they are commonly grouped with JavaScript reserved words.

## 6. Short summary
Keywords are the building blocks of JavaScript syntax. They tell the interpreter what action to perform.
