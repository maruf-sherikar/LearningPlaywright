# VS Code Commands for Windows

This file contains common Visual Studio Code commands and shortcuts for Windows in a simple table format.

| Action | Windows Command / Shortcut |
|---|---|
| Open Command Palette | Ctrl + Shift + P |
| Quick Open a file | Ctrl + P |
| New file | Ctrl + N |
| Save file | Ctrl + S |
| Save all files | Ctrl + Shift + S |
| Close current file | Ctrl + F4 |
| Close all files | Ctrl + K, Ctrl + W |
| Find in current file | Ctrl + F |
| Replace in current file | Ctrl + H |
| Find in all files | Ctrl + Shift + F |
| Open Explorer | Ctrl + Shift + E |
| Open Search | Ctrl + Shift + F |
| Open Source Control | Ctrl + Shift + G |
| Open Extensions | Ctrl + Shift + X |
| Toggle Sidebar | Ctrl + B |
| Toggle Terminal | Ctrl + ` |
| New Terminal | Ctrl + Shift + ` |
| Run selected code in terminal | Shift + Enter |
| Start debugging | F5 |
| Toggle Debug Panel | Ctrl + Shift + D |
| Open Settings | Ctrl + , |
| Go to line | Ctrl + G |
| Rename symbol | F2 |
| Format document | Shift + Alt + F |
| Comment line | Ctrl + / |
| Multi-cursor | Ctrl + Alt + Down/Up |
| Duplicate line | Shift + Alt + Down/Up |
| Move line up/down | Alt + Up/Down |
| Open integrated terminal | Ctrl + ` |

## Useful Notes
- Ctrl + Shift + P is one of the most powerful commands because it opens the Command Palette.
- You can search for almost any VS Code action from there.
- The integrated terminal is very useful for running JavaScript, Node.js, and Git commands.
